Alur pemesanan

Empat langkah dari brief sampai file akhir

  1. Isi form pesanan

    Pilih layanan, ceritakan kebutuhan, tentukan deadline, dan tempel link referensi kalau ada.

  2. Kirim lewat WhatsApp

    Pesan sudah terisi otomatis. Kamu tinggal menekan kirim, lalu menerima konfirmasi harga dan estimasi.

  3. Bayar DP

    DP dibayar sesuai kesepakatan. Metode pembayaran dikirim saat konfirmasi, lalu pengerjaan dimulai.

  4. Revisi dan pelunasan

    Cek hasilnya, minta revisi sesuai paket, lunasi, dan terima file akhir.
